# Financial Customer Complaints Analysis

## 📊 Project Overview
Financial Customer Complaints Analysis using **Excel, SQL and Power BI**. 
Data cleaning, complaint trends, customer issues, response analysis and interactive dashboard.

## 🎯 Objectives
- Analyze customer complaints by product, issue, and company
- Identify top complaint trends and patterns
- Analyze company response time and customer satisfaction
- Build interactive Power BI dashboard for decision making

## 🛠️ Tools Used
- **Excel** - Data Cleaning & Exploratory Analysis
- **SQL** - Data Querying & Aggregation
- **Power BI** - Data Visualization & Dashboard
- **GitHub** - Version Control

## 📁 Dataset
- Source: Consumer Financial Protection Bureau (CFPB)
- Records: 1M+ Customer Complaints
- Columns: Date Received, Product, Issue, Company, State, Submitted via, Company Response, Timely Response, Consumer Disputed

## 🧹 Data Cleaning (Excel / SQL)
- Removed duplicates and null values
- Standardized Date format
- Cleaned Product & Issue categories
- Created new columns: Year, Month, Quarter

## 🔍 Key Analysis (SQL)
1. Total complaints by Product
2. Top 10 Companies with most complaints
3. Complaints by Issue - Top issues
4. Timely Response % by Company
5. Year-wise & Month-wise complaint trend
6. State-wise complaints distribution

## 📈 Power BI Dashboard
- **KPI Cards:** Total Complaints, Timely Response %, Disputed %
- **Charts:** Complaints by Product, Issue-wise Bar Chart, Year-wise Trend Line
- **Filters:** Year, Product, Company, State
- **Map:** State-wise complaints

## 🔑 Key Insights
- Credit Reporting is the top complained product
- Most complaints are about Incorrect information on credit report
- 95%+ companies responded timely
- Complaints increased year by year
